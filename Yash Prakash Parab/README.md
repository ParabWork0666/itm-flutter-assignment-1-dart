### 📌 Repository Overview

A comprehensive, curated repository of **100 standalone Dart programs** demonstrating language fundamentals, control structures, mathematical algorithms, data manipulation, advanced **Object-Oriented Programming (OOP)** paradigms, mixins, abstract class architectures, and software design patterns.

Whether you are learning Dart for Flutter development, preparing for technical interviews, or mastering OOP principles, this repository serves as a complete reference guide with well-documented, clean, and executable code.

---

## 🚀 Quick Description (For Repository Header / About)

> **"A curated collection of 100 standalone Dart programs covering language fundamentals, control flow, mathematical algorithms, advanced OOP, mixins, dynamic dispatch, and design patterns."**

---

## 🛠️ Key Topics Covered

- ⚡ **Dart Fundamentals & Operators** (Types, Constants, String Interpolation, Bitwise Ops)
- 🔀 **Control Flow & Decision Making** (`if-else` ladders, `switch-case` with fall-through)
- 🔄 **Loops & Pattern Printing** (`for`, `while`, `do-while`, Floyd's & Pascal's Triangles)
- 🎯 **Functions & Parameter Flexibility** (Recursion, Named Parameters, Optional Positional)
- 🏗️ **Classes, Objects & Constructors** (Named Constructors, Redirecting `: this()`, Factory, Private Constructors)
- 🔒 **Encapsulation & Access Control** (Private `_` fields, Read-Only/Write-Only Getters & Setters)
- 🧬 **Inheritance & Runtime Polymorphism** (Single, Multi-Level, Method Overriding, Covariant Return Types)
- 🔌 **Abstract Classes, Interfaces & Mixins** (Multiple Mixins, Abstract Constructors, Template Method, Marker Interfaces)
- 💡 **Design Patterns & Advanced Idioms** (Singleton, Factory Method, Comparable Interface, Type Checking `is`/`is!`)

## 💻 Getting Started

### Prerequisites

Ensure you have the **Dart SDK** (v3.0 or higher) installed on your system.

```bash
# Verify installation
dart --version
```

### Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/your-username/dart-core-oop-masterclass.git
cd dart-core-oop-masterclass
```

---

## ⚡ Execution

Run any standalone program using the standard `dart` CLI command:

```bash
# Run program 1 (Hello World)
dart 1.dart

# Run program 83 (Factorial Benchmark)
dart 83.dart

# Run program 100 (Complete Class with Private Fields & Validation)
dart 100.dart
```
